# The qrab logo

The mark is a ring whose tail ends in a crab's claw: a Q, and the crab. The
wordmark `qrab` is drawn from the same parts, an 8-unit round-capped stroke
and the mark's ring, so the two always match. Every file is plain SVG
(circles, paths and strokes, no text, fonts, gradients or filters), so it
renders the same in a browser, a slide or a print shop.

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Claw coral | `#E4572E` | The mark |
| Ink | `#1C1F26` | The wordmark on light backgrounds, the one-color mark |
| White | `#FFFFFF` | The wordmark and mark on dark backgrounds |

## Use

- Keep clear space around the mark of at least half its ring's width.
- Use the mark down to 16 px; below 24 px, use the favicon file, which is
  cropped tighter.
- Scale the files; do not redraw, recolor (other than to the one-color or
  white versions), stretch or outline them.
